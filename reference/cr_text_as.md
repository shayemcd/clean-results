# Re-render report text in another format

Re-render report text in another format

## Usage

``` r
cr_text_as(x, format = c("markdown", "latex", "html", "plain"))
```

## Arguments

- x:

  A `cr_text` object from
  [`cr_report()`](https://shayemcd.github.io/clean-results/reference/cr_report.md).

- format:

  `"markdown"`, `"latex"`, `"html"`, or `"plain"`.

## Value

A `cr_text` object.
