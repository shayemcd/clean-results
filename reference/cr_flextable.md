# Render a results table as a flextable (Word, HTML, PowerPoint)

Render a results table as a flextable (Word, HTML, PowerPoint)

## Usage

``` r
cr_flextable(x, font = "Times New Roman", font_size = 10)
```

## Arguments

- x:

  A `clean_results` or `cr_table` object.

- font, font_size:

  Font family and size in points.

## Value

A `flextable`.
