# Figure palettes

`cr_palettes` holds the package palettes (Teal & Terracotta, Forest &
Lilac, Nordic Pine & Ochre, Partisan & Bridging) and the default
category orders the plotting functions use. The defaults were checked
for color-vision deficiency: every pair of colors stays distinguishable
for protan, deutan, and tritan readers. Slate and teal are nearly
identical for red-blind readers, so the defaults never use them
together.

## Usage

``` r
cr_palettes
```

## Format

A named list of character vectors of hex colors.
