# cleanresults: Publication-Ready Regression Tables, Text, and Figures

Fits linear, logistic, count, ordinal, mixed-effects, and Bayesian
regressions for one or more outcomes and renders a single
publication-ready table with robust standard errors, explicit reference
categories, pairwise contrasts, and multiple-comparison corrections
within factors and across outcomes. Builds results text, hypothesis
summaries, and figures from the same fitted objects, and checks numbers
typed in a manuscript against them. Tables render natively in Quarto
(HTML, Word, PDF) and export to Word, LaTeX (Overleaf), and HTML that
pastes cleanly into Google Docs.
